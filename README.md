# hello-world

Hello Humans!

A simple Python hello-world project with a complete build system.

## Building and Running

### Prerequisites
- Python 3.x
- Make (for build commands)

### Build Commands

```bash
# Build the project (compile/check syntax)
make build

# Run the application
make run

# Run tests
make test

# Clean build artifacts
make clean

# Show all available commands
make help
```

### Quick Start

1. Build the project:
   ```bash
   make build
   ```

2. Run the application:
   ```bash
   make run
   ```

## Project Structure

- `main.py` - Main Python application
- `Makefile` - Build system with various targets
- `README.md` - This documentation

## Output

The application outputs:
```
Hello Humans!
Welcome to the hello-world project!
```
